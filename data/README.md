# Research Data & Architecture Documentation

## 1. Raw Dataset Documentation

- **Dataset Identifier:** CPCB National Ambient Air Quality Monitoring Data (`city_day.csv`)
- **Primary Raw Location:** `final_analysis/city_day.csv` (root directory of the project workspace)
- **File Size:** ~2.57 MB (29,531 raw observations × 16 attributes)
- **Temporal Span:** January 1, 2015 through July 1, 2020 (5.5 years)
- **Spatial Coverage:** 26 Indian metropolitan and industrial cities:
  - Ahmedabad, Aizawl, Amaravati, Amritsar, Bengaluru, Bhopal, Brajrajnagar, Chandigarh, Chennai, Coimbatore, Delhi, Ernakulam, Gurugram, Guwahati, Hyderabad, Jaipur, Jorapokhar, Kochi, Kolkata, Lucknow, Mumbai, Patna, Shillong, Talcher, Thiruvananthapuram, Visakhapatnam.
- **Monitored Chemical Precursors:**
  - `PM2.5` ($\mu\text{g/m}^3$), `PM10` ($\mu\text{g/m}^3$), `NO2` ($\mu\text{g/m}^3$), `NH3` ($\mu\text{g/m}^3$), `SO2` ($\mu\text{g/m}^3$), `CO` ($\text{mg/m}^3$), `O3` ($\mu\text{g/m}^3$), `NO` ($\mu\text{g/m}^3$)
- **Target Variable:** `AQI` (Continuous integer index calculated according to Indian National Air Quality Index standards)

## 2. Processed Datasets

Processed, leakage-free partitions are generated by `NEW_ANALYSIS/scripts/01_preprocess.py` and stored in `NEW_ANALYSIS/data_processed/`:

1. `train_sub.csv` ($N = 7,556$ rows, 2015–2017): Used for model hyperparameter fitting and early stopping training fold.
2. `val.csv` ($N = 5,658$ rows, 2018): Chronological validation fold used strictly for early stopping and iteration selection.
3. `train.csv` ($N = 13,214$ rows, 2015–2018): Full development partition used for final model retraining prior to evaluation.
4. `test.csv` ($N = 11,410$ rows, 2019–2020): Untouched holdout test partition evaluated strictly once.

## 3. Note on Frontend Application Data

This directory (`data/`) also contains TypeScript interfaces and constants (`content.ts` and `models.ts`) used by the accompanying Next.js 15 interactive research dissemination application. These files reflect the audited and verified benchmarking metrics.
